# Changelog

All notable changes to Web Spider Pet are documented here.

## 0.1.0 — 2026-10-10

First public-ready prototype.

### Added

- Chromium Manifest V3 extension prototype.
- A geometric spider rendered as a transparent SVG overlay.
- Real DOM link discovery and viewport positioning.
- Procedural eight-leg locomotion with planted-foot two-bone IK.
- Gait-driven body movement, steering, acceleration and arrival slowdown.
- Continuous exploration of visible links.
- Slow automatic downward exploration when the current viewport is exhausted.
- Crawling that continues while the page scrolls, with page-surface foot projection.
- Single-target and continuous exploration modes.
- Demo page, automated locomotion checks, and a real-time demo recording.

### Not included yet

- AI / LLM integration.
- API-key support.
- Automatic link clicking or cross-page navigation.
- A native desktop-pet application.

The v0.1 goal is simple: make the crawler metaphor visible — the crawler is the spider. 🕷️
